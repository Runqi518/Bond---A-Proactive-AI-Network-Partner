# Bond UI direction

The deliverable lives in the original Companion App Figma file, on two pages: **Mobile · Bond UI** and **Web · Bond UI**. The original reference page remains intact.

Mobile contains eight 390 × 844 screens: the three principal tabs, person detail, create a person Agent, companion chat, scenario rehearsal, and meeting reflection. The Companion screen puts the AI practice card, two people, and the create/rehearse shortcuts above the bottom navigation. Today uses an asymmetric action grid; Meetings pairs a compact upcoming event with reflection and memory actions. Web contains a People dashboard and a person workspace at 1440 × 900.

The page surface is white. Functional cards use solid cream `#FFE16A`, sage `#9DB564`, light sage `#B2C785`, blue `#9BCBE5`, pink `#FFB6D9`, and ivory `#F5F1D8`. Black anchors the navigation and main actions. There are no decorative spheres, gradients, or floating cards. Text, shapes, cards, and frames are editable in Figma.

Spacing follows consistent 24 px mobile gutters, 10–16 px component gaps, and 16–20 px card radii. Labels stay inside card boundaries. The product copy is English and the user name is Riley.
